How it works

Six steps, end to end, all on-device.

1

Camera → Detection

CameraX delivers frames to TFLite YOLOv8n — object, currency, barcode, color in parallel pipelines.

2

Detections → World Model

SpatialEngine stabilizes tracks and maps every object to direction, distance (meters), and approach state.

3

Voice → Goal

GoalParser matches your phrase to an intent — no LLM, no network, zero hallucination.

4

Goal + World → Response

ResponseBuilder picks the right template: count, direction, distance — spoken naturally.

5

Response → Speech

Native Text-to-Speech reads it out at a comfortable pace.

6

Telemetry → Dashboard

Optional local WebSocket streams the world model to a live Command Center.

Built with

Everything runs on-device. No servers, no API keys, no subscriptions — it works anywhere, even offline.

Kotlin Jetpack Compose CameraX TensorFlow Lite YOLOv8n ML Kit OCR ML Kit Barcode Vosk (offline STT) Android DataStore Node.js + React WebSocket
